# ADR 0001: AI 미사용과 런타임 외부 통신 금지

- 상태: 승인
- 날짜: 2026-09-03

## 배경

입력 PCAP에는 사내 IP, MAC, 사용자 식별자, 인증 흐름, 서비스 주소 등 민감한 정보가 들어갈 수 있습니다. 대상 환경에서는 분석 데이터가 외부로 전송되지 않아야 하며, 초급 사용자에게도 같은 입력에 대해 검증 가능한 결과를 제공해야 합니다.

생성형 AI는 자유로운 설명을 만들 수 있지만 결과가 비결정적이고 외부 모델 공급자 또는 로컬 모델 서비스와의 통신 경계를 추가합니다. 외부 API, 텔레메트리, 자동 업데이트도 동일하게 불필요한 반출 경로가 됩니다.

## 결정

제품 런타임에서 AI와 모든 외부 통신 기능을 제거합니다.

- AI, LLM, Ollama, MCP, 모델 SDK를 사용하지 않습니다.
- 외부 API, HTTP 요청, 소켓, DNS 조회를 사용하지 않습니다.
- 텔레메트리, 오류 자동 전송, 사용량 수집, 자동 업데이트를 사용하지 않습니다.
- 수신 대기 포트와 로컬 웹 서버를 만들지 않습니다.
- API 키, 토큰, 서버 URL 설정을 제공하지 않습니다.
- 한국어 설명은 버전이 고정된 검수 문장 템플릿으로 생성합니다.
- 판정은 결정론적 JSON 규칙으로 수행합니다.

Git 원격 작업과 GitHub Actions가 사용하는 개발 인프라 네트워크는 제품 런타임과 구분합니다. 그러나 애플리케이션과 빌드 스크립트가 TShark, 모델, 규칙, 자산을 인터넷에서 자동 다운로드하는 것은 허용하지 않습니다.

## 강제 방법

- 런타임 의존성을 Python 3.13 표준 라이브러리로 제한합니다.
- 네트워크·AI 관련 Import와 외부 통신 문자열을 정적 검사합니다.
- `eval`, `exec`, `shell=True`와 문자열 셸 명령을 검사합니다.
- 생성 HTML에서 네트워크 참조와 JavaScript를 검사합니다.
- 비대화형 자체 점검은 창이나 네트워크를 만들지 않고 종료해야 합니다.
- Windows 오프라인 검증은 정적 검사와 실제 실행 검사를 구분합니다.

## 결과

장점:

- PCAP과 분석 데이터의 외부 반출 경로가 줄어듭니다.
- 동일 입력에 대한 설명과 판정을 재현할 수 있습니다.
- API 키, 모델 설치, 모델 품질 변화에 영향을 받지 않습니다.
- 보안 감사 범위가 작고 명확해집니다.

제약:

- 자유 형식 질문과 생성형 요약을 지원하지 않습니다.
- 새 장애 유형은 검토된 규칙과 문장을 릴리스해야 지원됩니다.
- 정적 검사만으로 운영체제 수준의 무통신을 완전히 증명할 수 없습니다.

## 검증 경계

GitHub-hosted Windows CI의 정적 감사 성공은 제품이 실제 환경에서 연결을 만들지 않았다는 완전한 증거가 아닙니다. 네트워크 어댑터 비활성 상태와 Windows 방화벽 아웃바운드 차단 상태의 실동작 검증은 패키징 단계에서 별도 수행하고 결과를 구분해 기록합니다.
