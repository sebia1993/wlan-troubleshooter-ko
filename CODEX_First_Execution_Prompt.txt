현재 저장소에 Windows 11용 완전 오프라인 무선 장애 PCAP 분석기 `wlan-troubleshooter-ko`의 기반을 구축한다.

작업 전에 저장소 루트의 `AGENTS.md`, `CODEX_IMPLEMENTATION_PLAN.md`, `IMPLEMENTATION_STATUS.md`, `docs/adr/`를 모두 읽고 충돌 여부를 확인한다. 최신 사용자 지시를 최우선으로 따르되 범위를 임의로 넓히지 않는다.

이번 작업에서는 Phase 0과 Phase 1만 수행한다.

Phase 0에서 다음을 수행한다.

1. Python 3.13 프로젝트와 저장소 골격을 만든다.
2. 런타임 의존성은 Python 표준 라이브러리만 허용한다.
3. AI, LLM, Ollama, MCP, 외부 API, 텔레메트리, 자동 업데이트, 네트워크 호출을 금지한다.
4. 실제 PCAP·PCAPNG, 사내 사이트 프로파일, 사용자 정보, 장비 설정, 로그, 보고서, 추출 파일, 승인되지 않은 바이너리가 커밋되지 않도록 한다.
5. 금지 Import, 외부 URL, `eval`, `exec`, `shell=True`를 탐지하는 정적 감사를 만든다.
6. Windows `windows-latest`와 Python 3.13에서 컴파일, 테스트, 감사, 자체 점검을 실행하는 CI를 만든다.

Phase 1에서 다음을 수행한다.

1. `tkinter/ttk`로 최소 한국어 애플리케이션을 만든다.
2. 완전 오프라인 상태, 파일 선택, 입력 기초 검증, Portable TShark 준비 상태, 아직 실제 분석을 지원하지 않는다는 사실을 표시한다.
3. PCAP·PCAPNG의 확장자, 정규 파일 여부, 최소 길이, 형식 식별 바이트를 검사한다.
4. 원본을 수정하지 않고 정상·오류·취소 시 정리되는 안전한 임시 작업공간을 만든다.
5. Raw Payload, 쿠키, Authorization, 비밀번호, 토큰, 사용자 ID 원문, 전체 IP·MAC, 절대경로가 로그에 남지 않도록 마스킹한다.
6. 버전이 있는 JSON 리소스 로더와 결정론적 정규화 직렬화를 만든다. 실제 장애 규칙은 아직 추가하지 않는다.
7. 승인된 `vendor/wireshark/`의 매니페스트와 SHA-256만 신뢰하는 TShark 경계를 만든다. 시스템 설치본 자동 탐색과 자동 다운로드를 금지한다.
8. TShark 인자는 프로그램이 고정하고 `shell=False`, 제한시간, 취소, `-n`을 강제한다. 실시간·원격 캡처, Lua, 임의 옵션은 거부한다.
9. 외부 참조, JavaScript, 프레임, 객체, 자동 새로고침, CSS 외부 참조를 거부하는 HTML 정책 검사기를 만든다.
10. 창을 띄우거나 네트워크를 사용하지 않는 `--self-test`를 만든다.

비교 대상 외부 저장소의 소스, 테스트, 문장, 이미지, 자산을 복사하지 않는다. 실제 사내 데이터와 실제 캡처를 만들거나 저장소에 추가하지 않는다. 테스트는 실행 중 생성한 최소 합성 바이트와 합성 JSON만 사용한다.

승인된 Portable TShark가 제공되지 않았다면 검증기와 안전한 실패 상태까지만 구현하고 실제 실행이 검증된 것처럼 보고하지 않는다. macOS 테스트와 Windows CI를 구분하고, 실제 GUI·방화벽·네트워크 어댑터·실제 캡처·패키징 미검증 범위를 명시한다.

모든 관련 테스트와 감사를 실제로 실행한다. 완료 보고에는 변경 파일, 실행 명령, 실제 결과, 차단 사항, 미검증 범위를 포함한다.

Phase 2의 실제 프로토콜 추출, 장애 판정, 완성형 보고서, 802.11·로밍 분석, 패키징은 시작하지 않는다.
